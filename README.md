# 錢錢手帳 App

這是一個以 HTML、CSS、JavaScript 建構的個人記帳與預算管理 PWA，可在瀏覽器直接使用，也支援安裝成桌面應用程式。

## 功能特色

* 新增收入／支出紀錄
* 記錄項目、金額、分類、日期、備註
* 每月預算設定與餘額計算
* 主頁總覽、明細列表、統計圖表
* 支出／收入分類自訂與圖示設定
* 匯出與匯入 JSON 資料備份
* 深色模式與多套佈景主題
* 擴充功能管理（例如小算盤）

## 快速開始

1. 進入以下連結:[https://zkl1016.github.io/MoneyBook/](https://zkl1016.github.io/MoneyBook/)。
2. 在瀏覽器中新增記錄，或前往設定頁調整預算、分類與主題。

## 本地開發說明

這是純前端靜態專案，無需額外安裝 Node.js 或後端服務即可開啟使用。
如果你希望以本機伺服器方式開啟，可使用任意靜態伺服器，或直接用瀏覽器開檔案測試。

## 使用建議

* 首次使用請先在設定頁自訂預算與分類。
* 請隨時進行匯出紀錄，因為此應用程式採不定時更新，有可能會清除資料，因此請隨時匯出紀錄，避免資料遺失。

## 版本與維護

此程式適合用來作為個人記帳工具，或進一步擴充成更完整的財務管理 App。
